# JonGem game sources

JonGem(https://jongem.com)이 호스팅하는 카피레프트 라이선스(GPL, MPL) 게임의, JonGem이 고친 소스예요.

이 게임들은 원작 라이선스에 따라 JonGem이 고친 버전의 소스를 누구나 받을 수 있어야 해요. 게임마다 폴더를 두고, JonGem에 올린 버전마다 태그(`<게임>-<버전>`)를 붙여요. 게임 페이지의 "고친 소스" 링크가 그 태그를 가리켜요.

- 각 폴더의 소스는 원작 저장소의 고정된 커밋에 JonGem의 변경(점수판 연결, 저장 연결, 한국어 화면 등)을 적용한 전체 트리예요.
- 각 게임의 라이선스는 그 폴더의 LICENSE 파일을 따라요. 이 저장소 전체에 하나의 라이선스를 붙이지 않아요.
- JonGem 사이트 자체의 코드는 이 저장소에 없어요.

---

Modified sources of the copyleft-licensed (GPL, MPL) games that JonGem (https://jongem.com) hosts.

Each game has its own folder holding the full tree: the original at a pinned commit with JonGem's changes applied (leaderboard and save hooks, Korean UI, and so on). Every version JonGem publishes is tagged `<game>-<version>`, and the game page's "modified source" link points at that tag. Each folder is under its own LICENSE file; there is no repository-wide license. JonGem's own site code is not here.
