# HyperSpace

JonGem(https://jongem.com)이 서비스하는 HyperSpace의 소스예요. 원작의 고정된 커밋에 JonGem의 변경을 적용한 전체 트리예요.

The source of HyperSpace as JonGem (https://jongem.com) serves it: the original at a pinned commit with JonGem's changes applied.

## JonGem이 고친 것 / What JonGem changed

- 점수판(점수)을 붙였어요.
  Added the score leaderboard.
- 폰에서 화면 양옆이 잘리지 않게 캔버스를 창 너비에도 맞추고, 한 번 누르면 궤도가 한 번만 바뀌게 터치 처리를 고쳤어요.
  Fits the canvas to the window width too, so phones see the whole screen, and a tap now switches orbit once.
